NexusIR Web Flasher 🛸

Install or update NexusIR firmware directly from your browser via Web Serial API. No development tools or drivers required!

Target: ESP32-C3 · Apple HomeKit Build (v1.5.8)

📌 How to Flash:

  1. Connect your ESP32-C3 device to your computer using a USB-C data cable.
  2. Select your preferred ecosystem above: Apple HomeKit or ESP RainMaker.
  3. Click Connect & Flash, choose the corresponding Serial Port (e.g. tty.usbserial-* or COM*).
  4. Select Install NexusIR & check Erase Device for clean setup.
🌐 Supported Browsers: Google Chrome, Microsoft Edge, Opera on Windows, macOS, and Linux.
